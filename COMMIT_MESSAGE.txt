Atlas map: full interaction + search & filters (INTERNAL-PORTAL)

Makes the map fully interactive and adds search + state zoom.

What's new
- Interaction: scroll-wheel zoom, click-drag pan and double-click zoom are
  on, and clicking a state now zooms the map to that state's bounds.
- Search box — geocodes any address, suburb, street, area or council across
  Australia (OpenStreetMap Nominatim, AU-scoped), lists matches, and flies to
  the pick (fits its bounding box, drops a marker with the full name).
- "Zoom to state" dropdown — jumps to any state's extent, or All Australia to
  reset. Clicking a state on the map keeps the dropdown in sync.

Scope / honesty
- Region, suburb and council *boundary* filters (cascading dropdowns + finer
  choropleth) need the SA-region and LGA boundary layers, which aren't connected
  yet — until then Search reaches any of those places by name. The UI says so.
- Search calls Nominatim from the browser at runtime (no key); it's rate-limited,
  fine for interactive use.

Verification
- tsc --noEmit clean
- npm run verify:engine — 23/23
- npm run build — /atlas and /atlas/map build
