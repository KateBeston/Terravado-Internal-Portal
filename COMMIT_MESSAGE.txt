feat(sharing): collaborate (write) access for guests — notes, documents, financials on a shared deal

INTERNAL PORTAL.

Finishes the first half of portal sharing: a guest whose share is
permission='collaborate' can now contribute to the shared deal, not just view it.

- Guest (on /shared/[clientId], when collaborate): edit the serviceability
  financials, add documents, and post deal notes. View-only guests still get the
  read-only view.
- Deal notes: a shared thread on the deal, visible to the host and all shared
  parties. The host posts and reads it on the person record's Sharing tab; the
  guest on the shared deal view.
- All writes go through guarded SECURITY DEFINER functions that check the caller
  is a collaborator on that specific deal (or, for notes, the host) — add_deal_note,
  add_deal_document, collab_update_finances — rather than broad cross-tenant write
  policies. The guest never needs the host's tenant id. collab_update_finances
  shallow-merges so structured income/liability lists survive.
