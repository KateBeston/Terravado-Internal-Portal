Atlas map: SA4 & SA3 region boundaries with level selector + cascading filter (INTERNAL-PORTAL)

Turns the map from state-only into region drill-down using the ABS ASGS boundary
files.

What's new
- Boundary-level selector: State / Territory, SA4 region, SA3 region. Finer
  levels load their GeoJSON on demand from /geo (not bundled), so the initial
  map stays light.
- Cascading "Filter to state" — at a finer level, choosing a state shows only
  that state's regions and zooms to it. Clicking a region zooms to it.
- ABS ASGS Edition 3 boundaries ingested: SA4 (108) and SA3 (359), converted
  from the ABS Shapefiles, simplified and slimmed to code / name / state (+ SA4
  parent on SA3), ~1.1 MB each, served as static files under public/geo.
- Honesty: finer levels are coloured by an INDICATIVE regional value (clearly
  labelled, not sourced) until ABS Regional Population / CoreLogic are
  connected. State level still uses the real/stub metrics + live ABS.

Not included
- LGA (council): the attachment supplied was a data.gov.au metadata record with
  no data file, so LGA isn't wired yet — needs the actual LGA GeoJSON/Shapefile.
- Suburb polygons deferred (too large to bundle; Search covers suburbs for now).

Verification
- tsc --noEmit clean; npm run build green.
- Booted next start: /atlas/map → HTTP 200; /geo/sa4.json served (200, ~1.1 MB).
