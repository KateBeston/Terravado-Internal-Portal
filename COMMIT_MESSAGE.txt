Add a Data Sources section to manage and log all data sources (INTERNAL-PORTAL)

One place to see every external source Terravado draws on, its live/fallback
status, how to connect it, and an activity log of the live checks.

What's new
- /data-sources (nav "Data Sources", gated on the integrations capability):
  - Live health cards for the sources that fetch at runtime (ABS, CDR) showing
    live vs fallback and the as-at / banks-returned.
  - "Check now & log" — runs the live ABS + CDR fetches and writes the outcome
    to the activity log.
  - All sources table from the integration registry: status badge, category,
    what it enables, and the env var / access needed to connect it.
  - Activity log of recent checks (live / fallback / error, with detail).
- data_source_events table (migration 0022), tenant-scoped RLS; service +
  checkDataSourcesAction.
- Integrations folded in: /integrations now redirects to /data-sources (the map
  and Smart Search "See Integrations" links still work).
