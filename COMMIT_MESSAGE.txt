Equity chain: run off actual current loan balances (INTERNAL-PORTAL)

The equity chain projected each owned property's loan from the modelling
assumptions. This lets you enter the actual outstanding balance per property so
usable equity reflects reality, falling back to the modelled balance where none
is set.

What's new
- currentLoanBalance on the property record (PropertyDetails) — stored in the
  existing properties.details jsonb, no migration.
- "Current loan balances" editor on /equity — set each owned property's actual
  outstanding loan, saved in one go (saveLoanBalancesAction).
- Equity chain uses it: the actual balance is backed out to a deposit % so the
  modelled loan starts at the real figure (no LMI on a held asset). Usable
  equity = projected value x release LVR - that balance, per owned property.

Verification
