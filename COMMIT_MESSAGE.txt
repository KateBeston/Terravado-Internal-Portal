Wire live CDR product data into the Lenders page (INTERNAL-PORTAL)

Pulls residential-mortgage product rates & fees from the public CDR Product
Reference Data APIs (no key, no consent, no accreditation) and shows them on the
Lenders page. Live by default; degrades to a clear note (never errors) if a bank
is unreachable.

How it works
- CDR is federated — each ADI exposes its own base URI — so a configurable list
  of banks is polled server-side: products (x-v:3) then a representative
  product's detail (x-v:4) for the variable rate, comparison rate and annual fee.
  Per-bank failures are skipped; result cached 6h.
- "Live product rates — CDR Open Banking" panel on /lenders lists what came back
  with a status note (how many banks returned).
- Env: CDR_PRODUCTS_ENABLED=off disables it; CDR_BANKS (JSON array of
  {brand, base}) overrides the bank list.

Honesty / verification
- tsc clean; build green. Booted next start: /lenders → HTTP 200, panel renders.
- The build sandbox can't reach the bank endpoints, so I verified the fallback
  (panel shows "No banks returned products"). On Vercel the live poll runs. The
  default bank base URIs are best-effort — if any are wrong those banks just
  don't appear; set CDR_BANKS to the confirmed ACCC-register base URIs to fix,
  no code change.
