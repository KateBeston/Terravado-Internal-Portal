Add a Valuations tab to the property record (INTERNAL-PORTAL)

Records each valuation event and surfaces the number that matters for finance:
the contract-vs-valuation variance and the lending value (the lower of the two).

What's new
- /properties/[id]/valuations tab — valuation events (date, type, valuer/lender,
  assessed value, basis, note) with full CRUD (add, edit in place, delete).
- Headline summary: contract/current price, latest valuation, variance, and
  lending value (lower of), with a shortfall warning spelling out that the
  borrower funds the gap and the LVR is assessed on the lower figure.
- Valuation type list: bank (full), desktop, kerbside, AVM, independent/sworn,
  contract price.
- Smart Search now drops its AVM estimate in as the baseline valuation.
- Nav: Valuations tab after Sales history. No DB migration (stored in the
  existing properties.details jsonb).

- npm run build — valuations tab builds
