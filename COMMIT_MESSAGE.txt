feat(stock): stock-list import — paste-and-confirm lot entry, with an AI-extraction seam for PDFs

INTERNAL PORTAL.

Completes the stock module's loose end: loading a development's stock without
typing each lot.

- StockImport on the development record: paste the stock list (copied from the
  developer's PDF or a spreadsheet), it parses each line into an editable confirm
  table (lot number, address, stage, price, beds, baths, land, rent, yield), you
  fix anything, then bulk-create the lots. Best-effort parse by design — every
  developer's layout differs — so every field is editable before saving and
  nothing imports blind. Delimiter and number handling cope with tabs, CSV,
  multi-space columns, thousands-commas and "$560pw"-style rent.
- importLotsAction bulk-creates the confirmed rows under the development.
- Extraction provider seam (lib/integrations/extraction), config-gated on
  STOCK_EXTRACTION_PROVIDER, registered on the Integrations page: when an LLM key
  is connected, a PDF upload will auto-extract rows into the same confirm table.
  Until then the paste path carries the feature. .env.example documents the var.

No migration — reuses the lots table. The embedded AI is unnamed for now (pending
a brandable, trademark-clear name — "Oracle" is taken by Oracle Corp).
