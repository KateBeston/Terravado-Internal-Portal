Atlas map: add LGA (council) boundary level (INTERNAL-PORTAL)

Adds councils to the boundary-level selector — I sourced the LGA polygons myself
since the data.gov.au file wasn't downloading for you.

What's new
- "LGA — council" level in the boundary selector (State / SA4 / SA3 / LGA),
  loaded on demand from /geo/lga.json, with the same cascading state filter and
  click-to-zoom as the other levels.
- LGA boundaries (563 councils) sourced from the public npm package
  `which-boundary` (ABS LGA shapefile, decoded from geobuf), simplified and
  slimmed to code / name / state, ~1.3 MB, served from public/geo.
- Finer-level note updated (councils now in; suburb level still to follow).

Notes
- These LGAs are the ABS 2016 edition (what that package ships) — council
  boundaries are largely stable, fine for the map; swap in a newer ABS LGA file
  later the same way if you want the latest.
- Still coloured by an indicative value until real regional data (ABS Regional
  Population / CoreLogic) is connected.

Verification
- tsc --noEmit clean; npm run build green.
- Booted next start: /atlas/map → HTTP 200; /geo/lga.json served (200, ~1.3 MB).
